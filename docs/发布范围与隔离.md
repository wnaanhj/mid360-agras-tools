# 发布范围与隔离

用户最终要求是“可自用、不可商用”，覆盖此前选择的GPL-2.0-or-later方案。GPL允许商用，因此不能给完整含GPL建图算法的软件统一加禁商用限制。本次选择源码公开的独立工具子集，不将它描述为完整可构建建图应用。

## 公开目录中的内容

10个独立Python生产模块、5个离线Python测试、5个纯JDK组件和1个Java测试，以及新编说明/示例/校验工具。没有完整建图滤波器、JNI库、APK或厂商程序。

唯一有功能裁剪的原模块是 `python/desktop/field_geometry.py`：原手机map.sqlite导入路径依赖完整建图集成，公开副本明确抛出说明错误；先从原软件导出二进制XYZ PLY/PCD再使用。其他选取模块只新增非商用许可头，没有修改运算逻辑。Java测试文件从原来的toolsCheck.java规范为公开类所需的ToolsCheck.java，内容逻辑不变。

## 仅本地核查，不上传

完整电脑版和手机版的当前源码、原生适配、JNI/ctypes、FAST-LIO与Point-LIO vendor，以及其必要构建依赖，存放在发布目录之外的本地隔离区。它们不是此仓库的一部分。隔离副本未通过完整许可核查，不是另一份可统一按非商用授权分发的成品。
