# 独立源码索引

所有坐标和正距离参数默认是米；例外会在接口注释中明确（例如clean_source使用厘米半径）。

| 文件 | 用途/入口 |
| --- | --- |
| [t100_stream.py](../python/radar_client/t100_stream.py) | decode_packet解包，StreamState维护预览，Receiver被动UDP接收；设备纳秒、主机单调时间分别使用 |
| [t100_preview_motion.py](../python/radar_client/t100_preview_motion.py) | project根据逐点时间、陀螺与外参进行显示补偿；时序不完整时返回不可用 |
| [repair_core.py](../python/desktop/repair_core.py) | apply_operation产生候选点、保留/移动/新增掩码及统计；支持取消 |
| [repair_resources.py](../python/desktop/repair_resources.py) | 估计物理内存与算法预算，检查资源，不承诺任意数据量均可处理 |
| [repair_compute.py](../python/desktop/repair_compute.py) | ComputeSession提供独立OpenCL点运算/失败信息；缺驱动时由调用方使用CPU |
| [white_cloud_filter.py](../python/desktop/white_cloud_filter.py) | clean_source读取点云并清理孤点；radius_cm为厘米；export_clean另存独立结果 |
| [field_geometry.py](../python/desktop/field_geometry.py) | 地图剖面/测距、坐标与只读文件辅助；本子集禁止依赖完整集成的手机SQLite导入 |
| [white_mesh_core.py](../python/desktop/white_mesh_core.py) | build_mesh/build_mesh_from_points构造有测量支持的局部面 |
| [white_building.py](../python/desktop/white_building.py) | build_building从Z向上的点中提取结构面；不是任意场景的完整房屋重建器 |
| [white_mesh_io.py](../python/desktop/white_mesh_io.py) | 二进制XYZ PLY/PCD分批读取；OBJ/GLB输出与原图路径保护 |
| [PointTools.java](../java/src/cn/t100/mapping/PointTools.java) | 纯Java点云修复；selection限制操作范围，推断点另有标记 |
| [WhiteMesh.java](../java/src/cn/t100/mapping/WhiteMesh.java) | 占用体素外露面转OBJ/GLB，不把体素面当实测表面 |
| [ToolHistory.java](../java/src/cn/t100/mapping/ToolHistory.java) | 磁盘快照与撤销重做；只操作专用历史目录 |
| [MotionPreview.java](../java/src/cn/t100/mapping/MotionPreview.java) | 有界陀螺历史、逐点显示投影；四元数顺序[w,x,y,z] |
| [UsbFrames.java](../java/src/cn/t100/mapping/UsbFrames.java) | Ethernet、ARP、非分片IPv4/UDP编解码，不管理USB设备 |

`python/windows`名称沿用原项目，其中本次提供的五组测试均不启动完整工作台。`java/test`验证点云工具、取消保护、白模文件结构与撤销重做。
