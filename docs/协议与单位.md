# 被动接收协议与单位

本文描述独立解析器接受的数据布局，不包含制造商固件、未公开文档截图或控制帧发送器。

参考地址：雷达192.168.1.10，接收端192.168.1.20/24。点云目的UDP60001，内置IMU目的UDP60003；实际地址和模式以自己的设备为准。地址是网络默认值，不是设备身份或账户凭据。

数据头为36字节的Livox SDK2式结构，解析器检查长度、类型、样点数量等结构。包头CRC字段不意味着本子集已对所有固件的CRC覆盖规则做了实机验证；不要把结构检查成功标成CRC验证成功。

- 高精度直角坐标：有符号32位整数，毫米转米。
- 低精度直角坐标：有符号16位整数，厘米转米。
- 球坐标：距离毫米，天顶角/方位角单位0.01度；轴约定见解析器和测试。
- IMU：陀螺rad/s、原始加速度g；这个子集不做SLAM滤波，不应在两层都重复转换加速度。
- 时间戳：设备纳秒；包内interval为0.1微秒单位。过滤零回波后必须保留原样点序号，不能把后面的点时间提前。
- 主机单调时间只用于缓存窗口、队列/断流观测，不代替设备点时间。

基础出点、采样使能、光学扫描周期、机械转速、建图更新率和显示刷新率是不同指标。被动收到点云/IMU只能确认正在输出数据，不能由包率反推出电机转速。

预览旋转补偿只用于显示；缺少IMU覆盖、时钟不一致或位姿陈旧时，应回退到明确的短窗/无补偿显示。它不能替代真实轨迹、运动外参标定或全局闭环。
